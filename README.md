# Wahid Zomato

Live website: https://wahidzomato.netlify.app

Wahid Zomato is a full-stack restaurant discovery and food ordering project inspired by Zomato. Users can browse restaurant categories, filter restaurants by location, cuisine, and price, view restaurant details, sign in, place an order, and continue through a Stripe checkout flow.

## Tech Stack

- React and Vite frontend
- Express and Node.js backend
- MongoDB database with Mongoose
- Stripe checkout integration
- Google and Facebook login options

## Deployment

- Frontend: Netlify
- Backend/API: Render

The frontend uses `VITE_API_URL` for backend API requests. The backend uses environment variables for MongoDB, Stripe, JWT, and the deployed frontend URL.
